ROHA

A simple two-player Tic-Tac-Toe style game where players can choose any two different letters from A–Z.

Features:

* Choose custom letters for Player 1 and Player 2
* 3×3 game board
* Two-player gameplay
* Score tracking
* Undo move
* Restart game
* Change letters
* Mobile-friendly responsive design
* Works with touch and mouse controls

 Technologies:

* HTML
* CSS
* JavaScript

 Play:

The game can be played directly in a web browser using the hosted version of the project.
